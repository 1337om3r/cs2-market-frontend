# 🎨 CS2 VAULT — Frontend

CS2 VAULT, Counter-Strike 2 skinlerini listeleyen modern bir marketplace arayüzüdür.  
Hafif, hızlı ve tamamen Vanilla JavaScript ile geliştirilmiştir.

---

## 🌐 Live Demo

👉 https://cs2-market-frontend.vercel.app/

---

## ⚙️ Özellikler

- 🔎 Canlı skin arama
- 💰 Fiyat sıralama (artan / azalan)
- 🎯 Filtreleme (price, wear, type)
- 📦 En ucuz & en pahalı skinler (spotlight)
- 📄 Sayfalama (pagination)
- 🖼️ Skin görselleri
- 🔗 Tek tıkla Steam Market’e gitme
